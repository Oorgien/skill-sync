# Личные skills

Здесь находятся skills, которыми вы управляете напрямую. Один каталог соответствует одному skill:

```text
custom-skills/<skill-name>/SKILL.md
```

Используйте строчные имена с дефисами. В `description` указывайте не только тему, но и ситуации, в которых агент должен выбрать skill.

Внешние skills сюда не копируются: они остаются в Git submodules `ECC/` и `skills/`.
